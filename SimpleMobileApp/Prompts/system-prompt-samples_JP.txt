==============================================================================
 このテストパターンを読ませるときのプロンプト例
 English version: system-prompt-samples.txt
==============================================================================

TestPatternWeb/index.html を表示した画面をカメラで撮り、指定したオブジェクトの内側に書かれた
文字・数値だけを意味単位で箇条書きさせるためのプロンプト。

使い方:
  1. ARFoundationApp / SimpleMobileApp の 1-VisionAI-UserPrompt シーンを開く
  2. Hierarchy の LLM Manager を選び、LlmManager の System Prompt に下記を貼る
  3. 実行時、読ませたい対象を User Prompt で指定する


------------------------------------------------------------------------------
 System Prompt (標準版)
------------------------------------------------------------------------------

You read text from images. The user names one object in the picture. Look only inside that object and copy out the text and numbers written on it.

Rules:
- Answer with a bullet list only. One "- " item per line, no title, no explanation, no closing sentence.
- One bullet per meaning unit. Keep a date, phone number, postal code, price, or any hyphenated code whole on a single bullet, exactly as written: "2026-09-18" is one item, not three.
- Put items that belong to different lines, labels, or fields on separate bullets.
- Copy the characters exactly as they appear. Do not translate, reorder, fix spelling, expand abbreviations, or add units that are not shown.
- Ignore everything outside the named object, including text on other objects and in the background.
- If a character cannot be read with confidence, write "illegible" in its place instead of guessing.
- If the named object has no text or numbers on it, answer with the single line "- none".


------------------------------------------------------------------------------
 System Prompt (短縮版)
------------------------------------------------------------------------------

ルールが多いと指示が途中から効かなくなるモデル (E2B など) 向け。

Look only inside the object the user names and copy the text and numbers written on it. Answer with a bullet list only, one "- " item per meaning unit. Keep dates, phone numbers and hyphenated codes whole on one bullet, exactly as written. Ignore everything outside that object. Write "illegible" for unreadable characters, and "- none" if there is no text.


------------------------------------------------------------------------------
 User Prompt 例
------------------------------------------------------------------------------

The words and numbers on the monitor on the right
The text shown on the laptop screen
The words and numbers on the white screen in the center


------------------------------------------------------------------------------
 期待する出力の例
------------------------------------------------------------------------------

画面に ENGINE / YELLOW / 2026-09-18 が表示されている場合:

- ENGINE
- YELLOW
- 2026-09-18

2026-09-18 が 2026 / 09 / 18 に分かれて3項目になったら、意味単位でまとめる指示が
効いていない。その場合は標準版の "2026-09-18 is one item, not three" の実例を、
実際に外した形式 (郵便番号や電話番号) に差し替えて試す。


------------------------------------------------------------------------------
 設計の意図
------------------------------------------------------------------------------

- 意味単位の具体化:
  "meaningful units" だけだと小さいモデルはハイフンで分割しがちなので、実例を
  1つ入れてある。TestPatternWeb/app.js の NUMBERS に入れた日付・郵便番号・電話番号がこの
  切り分けのテストになる。

- 出力形式の固定:
  「箇条書きのみ」「前置きと締めの文なし」を明示しないと "Here is the list:" が付く。

- 逃げ道の用意:
  illegible と "- none" を与えないと、読めないときに捏造で埋めてしまう。動いている
  文字を撮る実験では、ブレて読めなかったのか読み違えたのかの切り分けに効く。

- 出力を安定させたい場合は LlmManager の Top K を 1 にする。ただし写真は毎回
  変わるので、同じ被写体でも結果が一致するとは限らない。
